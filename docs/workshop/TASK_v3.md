## 6. B 部分：机制研究（`mechanism-v3`，只用 dev）
用 0.6B dev（14 篇）和 8B dev（14 篇）。每项一页结论，放 `docs/v3/b<编号>_*.md`。

- **B1 幂律核为什么赢**。目标是找出解释 0.310 的最小统计量。
  - 析因：核形状（指数 / 幂律）× 是否归一化 × 零点（第 K 个分数 / 中位数 / 最小值）。
  - 直接测试候选解释：
    - EMA(z) − λ·log(1 + 驻留步数)
    - EMA(z) − λ·log(1 + 距上次被选中的步数)。先读 `kvpolicy.Hybrid` 的定义，如果已经等价就直接引用它的结果。
    - 累计亏缺：Σ min(z, 0)，即"低于门槛多久、低多少"
    - 自驻留以来未被选中的步数
    - 快慢两个时间尺度的 EMA 的加权和（归一化）
  - 每个候选报告 B = 80、96、128、256 的 G 和与 EMA、幂律核的配对 ΔG。
  - 结论要回答：幂律核的优势来自核形状、不归一化，还是零点的位置；一个带显式驻留时间项的 EMA 能不能达到或超过它。
- **B2 G 为什么稳定**。
  - 每层每篇计算：相邻步 top-K 重合率、未选中 page 分数百分位的 lag-1 到 lag-64 自相关、重用距离分布、重复 miss 按"离开多少步后回来"分组的占比。
  - 看这些统计量能否解释各层 G 的差别（0.16–0.38）和各设置 G 的差别（0.27–0.31）：对文档做 LODO 的回归，报告 Spearman 相关。
  - 合成模型：每个 page 一个潜在分数过程（AR(1) 加慢变分量），每步取 top-K。用实测的自相关参数生成访问流，看 LRU、EMA、Bélády 的 miss 和 G 随 α、B/K 的曲线能否复现（特别是 α 的最优点随 B 增大、α 太大时低于 LRU）。
  - 第 10 层（G 0.16）和第 27 层（0.38）各做一个案例。
- **B3 剩下的差距在哪里**。
  - 有限前瞻的 Bélády：只知道未来 H 步（H = 1、4、16、64、256、全部），H 步内不再使用的 page 之间按 LRU 或 EMA 决定。画 G 随 H 的曲线，回答"要看多远的未来"。
  - EMA 的错误驱逐分类：被驱逐的 page 比 Bélády 的选择更早回来的那些，按驻留时间、分数百分位、回来的间隔、层、解码阶段（thinking / 回答）分组。
